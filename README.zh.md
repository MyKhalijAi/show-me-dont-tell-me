## 你每次都要浪费掉的那一分钟

你问某个设置在哪里。得到的回答是这样的：

> *「打开设置面板，找到「高级」区域，在靠近底部的位置查找下载选项。」*

三句话，零个像素。你还是得自己去找——而且如果这个回答来自对旧版本的记忆，那个选项可能早就不叫这个名字了。

**show-me-dont-tell-me** 回答同一个问题的方式是：给你一张**你自己屏幕**的图，红色的 ① 就落在那个按钮上。

一个步骤 = 一张标注图 + 一句操作说明。文字从不重复图片已经说清楚的内容。

## 有什么不同

| 没有它 | 有了它 |
|---|---|
| 「打开设置面板并找到下载选项」 | 一张图，红色 ① 落在确切的按钮上 |
| 根据旧版本臆造的界面文案 | 从你的屏幕或 i18n 文件中读取的真实文案 |
| 只讲顺利路径 | 空状态、校验错误、权限不足 |
| 带着真实客户数据的截图就这样发出去 | 脱敏是必经步骤，不是事后补救 |
| 「这需要一点时间」 | 「100 Mbps 下约需 25 分钟」 |
| 一大段需要自己解码的文字 | 一张图、一个动作、一个可验证的结果 |

## 人们实际拿它做什么

**📘 交付那份一直在拖的用户手册。** 把它指向你的代码仓库，它会读取路由、模板和 i18n 文件，产出一份连你自己都会遗漏的界面都覆盖到的教程——包括错误状态。

**🧑‍💻 不用开会就能带新人上手。** 「把我们的部署流程写成文档」会变成一份编号、配图的文档，每一步之后都附带验证信号。

**🎫 把一张工单变成一劳永逸的答案。** 排障模式给出：原因 → 修复 → 验证，错误画面和修复画面都有截图。贴进帮助中心，同一个问题不用回答第二次。

**🧭 在从没见过的界面里脱困。** 实时模式在每条指令前重新截取你的屏幕，绝不会引导你操作一个你早已离开的面板。

**🎬 按下录制前先把录屏分镜做好。** 编号镜头、每个镜头的时长，口播文案与屏幕文字分开列出。

## 四种模式，自动判别

它会先判断你需要什么，再动手。模式决定截图密度、结构和输出格式。

| 模式 | 触发方式 | 输出 |
|---|---|---|
| **实时** | 「帮我…」「我卡住了」 | 简短消息 + 每步一张图 |
| **文档** | 「写文档」「给我的应用做教程」 | 结构化文档，图片内嵌 |
| **排障** | 具体的报错、「这个用不了」 | 原因 → 修复 → 验证 |
| **脚本** | 「视频」「录屏」「培训」 | 编号镜头，逐镜头标注时长 |

它还会根据受众调整用语——终端客户、内部团队，或者半年后的你自己。

## 五条永不破例的规则

正因如此，它的输出可以直接贴进你的文档：

1. **绝不凭记忆描述界面。** 先有真实截图或源代码，再动笔。如果什么都拿不到，它会明说并向你索取——绝不猜测按钮在哪。
2. **先脱敏，再标注。** 邮箱、API 密钥、客户名称、浏览器标签栏。用模糊而非色块遮挡，让读者仍能看出那里有一个输入框。
3. **标记编号 = 步骤编号。** 永不错位。
4. **每一步都以验证信号收尾**——你应该看到什么，才能确认这一步成功了。
5. **每张图最多五个标记。** 超过就拆分。

完成后，它会重新审视自己刚生成的图片，逐条核对这五点——因为放错位置的标记比没有标记更糟。

## 指向你自己的代码库——这才是它真正的优势

拿到源码访问权限后，它先读代码，再截图：

- **i18n 文件、模板、常量** → 逐字准确的界面文案，语言正确
- **路由、控制器、校验器** → 那些你压根想不到要展示的界面
- **错误分支** → 空列表、字段非法、加载中、权限不足、配额用尽、网络失败
- **前置条件** → 第 1 步之前所需的角色、数据或设置，开头就交代清楚

> 跳过校验错误的那份教程，正是会产生工单的那一份。

## 为真实产品而做，不是为演示截图

- **认真处理的 RTL。** 在阿拉伯语和希伯来语界面中，标记移到目标**左侧**，箭头朝右，阅读顺序从右到左——而且它会在生成的图片上验证，而不是凭记忆。
- **无障碍是内建的。** 含义绝不单靠颜色传达：由编号承担。每张图片必须有替代文本。文字缩小一半后仍须清晰可读。
- **用你的语言回答。** 你用中文提问就得到中文——同时界面文案仍按屏幕上的原样逐字引用。
- **经得起时间。** 每份教程都标注日期和对应的应用版本，并且绝不在没有重新截图的情况下修改相关文字。

## 标注工具

`scripts/annotate.py` —— 一个实现了上述约定的 Pillow 小封装。无框架，无构建步骤：

```python
from annotate import Annot

(Annot("capture.png")
    .blur(120, 300, 420, 28)        # 先脱敏
    .frame(980, 550, 460, 50)
    .point_at(980, 575, 1)          # 标记 + 箭头，支持 RTL
    .crop_around(1100, 500, 1000, 600)
    .save("step-01-download.png"))
```

`set_rtl(True)` 会为阿拉伯语和希伯来语镜像标记位置与箭头方向。

## 第五份教程的成本只是第一份的零头

每个产品一个目录，让积累产生复利，而不是每次从零开始：

```
<产品>/
  captures/      原始截图
  annotated/     成品图
  glossary.md    准确的界面文案，按语言分列
  style.md       配色、字体、窗口宽度、演示数据集
  flows/         每份教程一个文件
```

在从零开始之前，它会先确认该流程是否已经存在、是否只需更新。
